====================================================
ARCHITECTURE REGELS
====================================================

1. ReadinessScan + ReadinessCheck worden de primaire bron van waarheid.

2. ReadinessCategory wordt uitsluitend berekend uit score:

0-20 = NOT_STARTED
21-40 = BASIC
41-60 = ADVANCED
61-80 = READY
81-100 = FULLY_COMPLIANT

3. Tenant context mag NOOIT uit request parameters komen.

Gebruik uitsluitend:

Authenticated User
→ Membership
→ Organization

4. Klanten worden standaard gearchiveerd.

Gebruik archivedAt.

Geen hard delete.

5. Audit logging verplicht voor alle mutaties.
